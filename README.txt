AVENGERS DATABASE — CHARACTER PROFILE PAGES

Included: 28 standalone HTML profile pages matching the href filenames in your current Avenger photos.html.

How to use:
1. Extract this ZIP.
2. Copy all 28 .html files into the same folder as index.html and Avenger photos.html.
3. Keep the filenames exactly as provided (including the space and capitalization in "Iron Man.html").
4. Open Avenger photos.html and click View Profile.

Important:
- The pages are designed to match the dark/red Avengers Database style.
- Film appearances may include cameos or post-credit scenes where noted.
- Some characters have multiple adaptations/universes; the notes distinguish those where relevant.
- Moon Knight's main MCU appearance is a TV series, not a feature film.
